# Telegram Video Bot

Телеграм-бот для автоматического анализа видео с помощью нейросети. Принимает ссылку на видео, обрабатывает контент и выдает краткое резюме с ключевыми моментами.

## ✨ Возможности

- 📹 Поддержка YouTube, Vimeo, TikTok, Rutube, VK Video и других платформ
- 🤖 Анализ контента через Claude API
- 📝 Автоматическое извлечение субтитров и транскрипции
- 🖼️ Создание заметок на основе видео контента
- 🏷️ Генерация тегов для контента
- 🗂️ Личные папки с заметками для каждого пользователя (команда `/notes`)
- ✏️ Ручное редактирование текста и названия сохранённых заметок
- Для рецептов: название блюда становится названием заметки, ниже идут
  «Продукты» и «Приготовление». Количества и неточные определения берутся
  только из источника; реклама, промокоды и продвижение исключаются.

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
python -m pip install --upgrade -r requirements.txt
```

### 2. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируйте `.env` и вставьте ваши ключи:

```
TELEGRAM_BOT_TOKEN=ваш_токен_бота
OPENAI_API_KEY=ваш_api_ключ
```

### 3. Запуск бота

```bash
python telegram_video_bot.py
```

Либо, на Windows, через управляющие скрипты — см. раздел [Управление ботом (Windows)](#️-управление-ботом-windows).

## 📖 Использование

1. Откройте бота в Telegram
2. Отправьте команду `/start`
3. Отправьте ссылку на любое видео
4. Дождитесь анализа
5. Получите структурированное резюме!
6. Выберите папку, в которую сохранить заметку (или создайте новую)
7. Через `/notes` в любой момент откройте свои папки, просмотрите или отредактируйте заметки

## 🔧 Требования

- Python 3.11+ (для актуальных версий yt-dlp)
- Доступ к интернету
- Telegram Bot Token
- API ключ для Claude (через polza.ai)

## 🖥️ Управление ботом (Windows)

Чтобы не держать открытой консоль, бот можно запускать и останавливать скриптами — они сами следят за процессом через `bot.pid` и пишут вывод в `logs\`:

- **`start_bot.bat`** — запускает бота в фоне (без видимого окна консоли)
- **`stop_bot.bat`** — корректно останавливает запущенного бота
- **`restart_bot.bat`** — перезапуск (стоп + старт), удобно после обновления `telegram_video_bot.py`
- **`status_bot.bat`** — показывает, работает ли бот сейчас; если бот упал при старте — покажет последние строки из `logs\bot.err.log`

Достаточно дважды кликнуть нужный `.bat`-файл в папке проекта. Если Windows заблокирует запуск PowerShell-скрипта политикой выполнения — `.bat`-файлы уже вызывают `powershell -ExecutionPolicy Bypass`, так что дополнительная настройка не нужна.

## 🛠️ Развертывание

### Ошибка YouTube «SSL: INVALID_SESSION_ID»

Ошибка возникает при установке TLS-соединения с видеосервисом, ещё до анализа
через AI. Она может быть связана с сетевой фильтрацией или VPN/прокси.
DoH-fallback в боте помогает только при ошибке DNS и не исправляет TLS.

1. Обновите зависимости тем же Python, которым запускаете бота:

   ```powershell
   python -m pip install --upgrade -r requirements.txt
   python -m yt_dlp --list-impersonate-targets
   ```

   В списке должна быть доступна цель Chrome. Бот по умолчанию использует
   `curl_cffi` с браузерным TLS. Метаданные и субтитры идут через один клиент.
   Проверка сертификатов остаётся включённой.

2. Если ошибка сохраняется, проверьте доступ к YouTube с компьютера, где
   запущен бот. VPN только в расширении браузера не распространяется на Python.
   Включите VPN для всего компьютера или укажите в `.env` адрес HTTP/SOCKS-прокси
   из настроек вашего VPN-клиента:

   ```dotenv
   VIDEO_IMPERSONATE=chrome
   VIDEO_PROXY=http://127.0.0.1:PORT
   ```

   Замените `PORT` реальным портом. Не используйте случайные публичные прокси.
   Без `VIDEO_PROXY` yt-dlp использует обычные настройки прокси окружения.
   `VIDEO_IMPERSONATE=none` позволяет отключить браузерный TLS для диагностики.

   Для Happ адрес SOCKS5-прокси можно посмотреть в «Настройки → Inbounds».
   Если там указан порт `10808`, используйте
   `VIDEO_PROXY=socks5://127.0.0.1:10808`. Happ должен оставаться подключённым.

3. Перезапустите бот через `restart_bot.bat` и повторите отправку ссылки.
   Подробности ошибок находятся в `logs/bot.err.log` при запуске через скрипты.

Скрипты Windows используют `.venv/Scripts/python.exe`, если такое окружение
создано в папке проекта. Иначе используется `python` из PATH. Для установки
зависимостей в существующее окружение запускайте
`.\.venv\Scripts\python.exe -m pip install --upgrade -r requirements.txt`.

Проверить получение метаданных и русских субтитров без Telegram и платного AI
можно из папки проекта (команда загружает настройки `.env`):

```powershell
python -c "from dotenv import load_dotenv; load_dotenv(); from video_processor import VideoProcessor; info = VideoProcessor().extract_video_info('https://www.youtube.com/watch?v=II-j5J1gSJc'); print(info['title']); print('Subtitle characters:', len(info['subtitles']))"
```

### Ошибка внешнего AI-сервиса

Актуальный адрес Polza.ai: `https://polza.ai/api/v1`. Укажите его в `.env`
как `EXTERNAL_API_URL`. Адрес `https://api.polza.ai/api/v1`, указанный в старой
версии проекта, при проверке завершался по тайм-ауту. Документация сервиса:
https://polza.ai/docs.

Модель задаётся через `EXTERNAL_API_MODEL` (по умолчанию `z-ai/glm-5.3-flash`).
После изменения настроек перезапустите бот. При ошибке AI бот прекращает
создание заметки и объясняет причину: тайм-аут, неверный ключ, оплата или лимит.
Для тегов ограничен размер ответа, чтобы не запрашивать лишние токены.
